# Implementation History

- **Changes**: 파일 카드 10분 유효 안전 공유 링크 생성 및 전용 다운로드 뷰어 페이지 구현

## 1. 개요 및 변경 배경
- 저장된 파일 카드를 다른 사람에게 공유할 때, 영구적으로 노출되지 않고 **정확히 10분 동안만 유효하게 열람 및 다운로드**할 수 있는 안전 공유 링크 기능을 추가하였습니다.
- 다중 파일이든 단일 파일이든 하나의 링크로 전달하여 수신자가 웹에서 10분 카운트다운 타이머와 함께 개별/일괄 다운로드할 수 있도록 전용 뷰어를 제공합니다.

## 2. 세부 구현 사항
1. **무상태 HMAC 보안 서명 토큰 유틸리티 (`lib/shareToken.ts`)**:
   - Node.js `crypto` 모듈을 활용하여 파일 메타데이터(파일명, 크기, Storage 경로)와 10분 만료 시간(`exp: Date.now() + 10m`)을 포함하는 무상태(Stateless) HMAC-SHA256 토큰 생성 및 검증 엔진 구축.
   - DB에 임시 토큰을 저장할 필요가 없어 데이터베이스 쿼리 비용 0회, RLS 정책 제약 없이 가볍고 안전한 검증 지원.
2. **공유 API 라우트 (`app/api/share/route.ts`)**:
   - `POST /api/share`: 요청된 파일 목록을 기반으로 10분 만료 서명 토큰 발행.
   - `GET /api/share?token=...`: 토큰 서명 및 만료 시간을 검증하고, 유효 시 각 파일의 Supabase Storage 서명 다운로드 URL(`createSignedUrl`)을 남은 시간만큼 한시 발급. 10분 초과 시 `410 Expired` 반환.
3. **10분 안전 공유 뷰어 페이지 (`app/share/[token]/page.tsx`)**:
   - 비로그인 수신자도 자유롭게 접속 가능한 독립적인 웹 공유 페이지.
   - AnyShare 브랜드 헤더 및 실시간 10분 만료 카운트다운 타이머(`MM:SS`) 표시.
   - 파일 목록(파일명, 포맷팅된 용량, 개별 다운로드 버튼) 및 전체 일괄 다운로드 지원.
   - 10분이 경과하거나 유효하지 않은 경우 즉시 접근 차단 및 만료 안내 화면 전환.
4. **카드 UI 연동 (`components/ItemCard.tsx`)**:
   - 파일 카드의 상단 퀵 액션 바 및 카드 헤더/버튼 영역에 '10분 공유 링크' 버튼(`Link2`) 추가.
   - 클릭 시 원클릭으로 토큰 발급 및 클립보드 복사(`https://domain/share/[token]`).
   - 복사 완료 시 카드 내부에 "⏱️ 10분 유효 공유 링크가 복사되었습니다!" 토스트 피드백 표시.

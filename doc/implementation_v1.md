# Implementation History

- **Version**: v1.2
- **Date**: 2026-10-21
- **Changes**: 다중 파일 동시 첨부 시 단일 카드로 묶음 표시 및 개별/전체 다운로드 지원 기능 구현

---

## 1. 개요 및 변경 배경
- 다중 파일 첨부 시 파일 개수만큼 개별 카드가 여러 개 생성되던 동작 방식을 개선하여, **한 번에 여러 파일을 올릴 경우 하나의 카드에 파일들이 목록으로 표시**되고 각 파일별 개별 다운로드 및 전체 일괄 다운로드가 가능하도록 고도화하였습니다.

## 2. 세부 구현 사항
1. **데이터 모델 확장 (`types/item.ts`)**:
   - `ItemMetadata`에 `files?: FileMetadata[]`를 추가하여 다중 파일 목록을 구조화하고, 기존 단일 파일(`file`)과의 100% 하위 호환성을 유지.
2. **입력 및 등록 로직 (`components/QuickInputBar.tsx`)**:
   - 다중 파일이 첨부된 경우 모든 파일을 Supabase Storage에 업로드한 뒤, **단일 카드(`type: 'file'`)**로 묶어 등록하도록 변경.
   - 카드 제목은 사용자가 작성한 메모가 있으면 해당 메모를 제목으로 지정하고, 비어있는 경우 `${첫번째파일명} 외 N개` 형태로 자동 요약.
3. **카드 렌더링 및 다운로드 (`components/ItemCard.tsx`)**:
   - 파일 목록(`filesList`) 개수에 따른 유연한 뷰 분기:
     - **단일 파일**: 기존의 직관적인 단일 파일 다운로드 카드 뷰 유지.
     - **다중 파일**: 상단에 총 파일 개수 및 총 용량 요약, '전체 다운로드' 일괄 다운로드 버튼 제공, 하단에 스크롤 가능한 개별 파일 리스트(파일명, 용량, 개별 다운로드 버튼) 제공.
   - 브라우저 다운로드 차단을 방지하기 위해 전체 다운로드 시 순차적 딜레이(400ms) 트리거 적용.
   - 카드 삭제 시 Storage에 보관된 다중 파일 경로(`storagePaths`)를 일괄 정리하도록 연동 (`hooks/useItemsRealtime.ts`).
4. **용량 계산 통일 (`app/page.tsx`, `components/StorageUsageModal.tsx`)**:
   - 다중 파일 번들 카드의 총 파일 용량도 누락 없이 정확히 합산되도록 집계 로직 반영.

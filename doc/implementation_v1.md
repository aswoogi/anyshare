# Implementation History

- **Version**: v1.5
- **Date**: 2026-10-21
- **Changes**: 이미지 파일 인라인 썸네일 미리보기 & 전체화면 라이트박스(Lightbox) 뷰어 구현

---

## 1. 개요 및 변경 배경
- 저장된 파일이 이미지(`image/*`, `.jpg`, `.png`, `.gif`, `.webp`, `.svg`, `.avif` 등)인 경우, 다운로드하지 않고도 카드 상에서 내용을 즉시 확인할 수 있는 **인라인 썸네일 미리보기**와 **전체 화면 라이트박스 뷰어**를 추가하였습니다.
- 단일 이미지 카드 및 다중 파일 카드 모두 지원하며, 10분 유효 안전 공유 페이지(`app/share/[token]/page.tsx`)에서도 공유받은 이미지들을 동일하게 라이트박스로 감상할 수 있습니다.

## 2. 세부 구현 사항
1. **이미지 파일 판별 유틸리티 (`lib/utils.ts`)**:
   - `isImageFile(filename, mimeType)` 함수 구현: 확장자 및 MIME 타입 기반 판별.
2. **모던 라이트박스 컴포넌트 (`components/ImageLightboxModal.tsx`)**:
   - 풀스크린 다크 오버레이 및 부드러운 애니메이션.
   - 확대/축소(`Zoom In/Out`, 최대 4배, 배율 실시간 표시), 90도 회전(`RotateCw`), 단독/일괄 다운로드 연동.
   - 키보드 단축키 지원: `Escape`(닫기), `ArrowLeft`/`ArrowRight`(이전/다음 이미지 탐색), `+`/`-`(확대/축소).
   - 다중 이미지 시 이전/다음 네비게이션 버튼 및 하단 썸네일 스트립 네비게이션 바 제공.
   - 배경(백드롭) 클릭 또는 닫기 버튼으로 간편 종료.
3. **메인 피드 파일 카드 연동 (`components/ItemCard.tsx`)**:
   - **단일 이미지 카드**: 카드 상단에 최대 높이 240px의 반응형 대형 썸네일 노출, 호버 시 '크게 보기' 오버레이 표시.
   - **다중 파일 카드**: 첨부 파일 중 이미지만 추출하여 상단에 3열 미니 썸네일 그리드 표시(4개 이상 시 `+N` 배지 오버레이).
   - 파일 목록 행의 개별 이미지에도 미니 썸네일 아이콘 및 돋보기 호버 효과 제공.
4. **10분 안전 공유 뷰어 페이지 연동 (`app/share/[token]/page.tsx`)**:
   - 외부 수신자용 뷰어 페이지에서도 동일하게 이미지 미리보기 박스 및 라이트박스 뷰어 제공.

## 1. 개요 및 변경 배경
- 모바일(스마트폰) 환경에서 가로 폭이 좁을 때 파일명과 다운로드/공유 버튼이 겹치거나 파일명이 잘려 보이지 않던 레이아웃 문제를 해결하였습니다.
- PC 환경에서도 파일 카드의 '10분 공유 링크' 버튼이 호버 여부와 상관없이 항상 눈에 띄게 노출되도록 개선하고, 다중 파일 내 각 파일별 개별 공유 링크 생성 기능도 추가하였습니다.

## 2. 세부 구현 사항
1. **모바일 반응형 레이아웃 2단 분기 (`components/ItemCard.tsx`)**:
   - **단일 파일 카드**:
     - 모바일: 1행에 파일 아이콘 및 전체 파일명(긴 파일명도 `break-all`로 시원하게 표시), 2행에 분리된 버튼 바(`[10분 공유 링크]`, `[다운로드]`)를 전폭 균등 배치하여 파일명이 버튼에 절대 가려지지 않음.
     - PC (`sm:` 이상): 좌측 파일 정보 + 우측 버튼 그룹으로 1행 배치 최적화.
   - **다중 파일 카드 헤더**:
     - 모바일: 1행 헤더 요약 정보 + 2행 버튼 바 분기 처리로 작은 화면에서도 버튼 겹침 현상 원천 차단.
   - 카드 본문 영역의 우측 여백을 `pr-2 sm:pr-14`로 조정하여 모바일에서 카드 본문 가로 폭을 최대 활용.
2. **PC 및 모바일 상시 공유 링크 노출 & 가시성 강화**:
   - 카드 우측 상단 퀵 액션 바뿐만 아니라 파일 카드 본체 자체에 **'10분 공유 링크'** 버튼을 뚜렷하게 상시 배치.
   - 다중 파일 목록의 개별 파일 행에도 각각 10분 공유 링크 복사 버튼(`Link2`) 추가.
3. **전용 10분 안전 공유 웹 뷰어 (`app/share/[token]/page.tsx`) & API**:
   - 기존과 동일하게 무상태 HMAC 서명 토큰 및 실시간 카운트다운 타이머 동작 유지.
